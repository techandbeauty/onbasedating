# OnBase — Waitlist

Landing page for early access sign-ups.

## Stack

- HTML / CSS / vanilla JS (no build step)
- Firebase Firestore for form submissions
- Cloudinary for video hosting

## Local development

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Deployment

Hosted via GitHub Pages from this repo.

## Files

- `index.html` — markup
- `styles.css` — styling
- `script.js` — Firebase config + page interactivity
- `assets/` — images
